A **private research lab** to understand colony sim architecture (inspired by RimWorld), build a minimal working simulation, then create a modern scalable engine.

**Based on**: Underscore's GTA San Andreas reverse engineering + Claude Code agents method.

**Not**: A commercial clone, redistribution, or legal risk project.

## FAQ

**Q: Is this legal?**
A: Yes. It's private research, decompilation is permitted for personal use, and all code is written originally. See PROJECT_CHARTER.md.

**Q: Do I need to code?**
A: You brief the LLM using LLM_SYSTEM_PROMPT.md. The agent does the coding. You review and validate.

**Q: Can I start coding now?**
A: Not yet. Phase 0 cartography must finish first. It's only 1-2 weeks. Use PHASE_0_CHECKLIST.md.

**Q: What if I get stuck?**
A: Mark it "TODO" and move on. Phase 0 is research, not blockers.

**Q: When do I see a running game?**
A: End of Phase 1 (~3-4 weeks). It will be headless (no graphics), but fully deterministic and tested.
